# ReSeam patch build contract

Preserve the working, repeatable process, updated October 26, 2026.

1. **Check both version boundaries before touching source.** Get the latest released ReSeam Manager/engine from the official project (not an older chat), AND the target app's latest build from the developer's own release channel when available. APKMirror may lag developer Telegram beta releases (Smart Launcher 6.6 build 024 appeared October 23).
2. **Keep the app version separate from the ReSeam engine version.** Manager and signed bundle engine are compatible only within ReSeam's documented 0.x minor release line. Changing the engine does not prove support for a new app APK. Advertise only bytecode-verified app builds.
3. **Isolate each app's Gradle bundle workspace and identity.** Smart Launcher build 024 uses `giraffe-smartlauncher` to avoid potential collision with legacy `giraffe-patches`; preserve the signing key even when renaming bundles. Don't equate build/signature checks with applying a patch. The manual workflow now fetches the developer's official direct APK, verifies its build number, applies the patch with CLI 0.31.0, and captures a non-APK log. If the fetched version differs, don't claim patch-stage verification. Smart Launcher older build 021 remains separately available.  For Smart Launcher, use `projects/smartlauncher`; for Icon Pack Studio, use `projects/iconpackstudio`. Set `app.reseam.workspace` plugin to the exact CLI version, and install `reseam-linux-x64` from the matching `https://cdn.reseam.app/engine/vX.Y.Z/` path.
4. **Reuse the proven Kotlin patch and precise matchers** instead of broadening to obfuscated classes of unknown builds. Smart Launcher 021 required exact purchase-owner class `Lmn8;` after broad broadcast-string match yielded 11 classes; build 024 was separately inspected and uses `Li89;` (while `Lmn8;` still exists but is unrelated); signature-check patch is an internal dependency. Icon Pack Studio 2.4/2.5 uses a semantic LicenseStatus string matcher plus a separately verified billing helper.
5. **Preserve the permanent Ed25519 identity.** GitHub secret `RESEAM_SIGNING_KEY_BASE64` contains a 32-byte seed; public key is `9b5228381bdce62d03e9df9654f02c9ceb9c06fd67722aa201a6c01cc989d89b`. Never print or commit the seed. Verify `manifest.pubkey`, `manifest.sig`, manifest engine version, file hashes, `bundle list` and advertised app versions.
6. **Build once, manually only.** Do not enable schedules, push/PR/tag-triggered workflows, recurring monitoring, automatic reruns, or unattended releases. Use a dedicated `workflow_dispatch` per app. Inspect compilation and signature steps before delivering artifacts.
7. **Deliver the actual `.reseam` file, not its source ZIP.** Download the successful Actions artifact and extract the one `.reseam`. Verify its bytes and integrity in the active container and link the *confirmed* sandbox file; on some ChatGPT Android clients, files previously generated by a tool may show 'Library file not found'. Regenerating a current-session container file produced a working direct link. Provide an optional ZIP backup; do not claim download success without user confirmation.
8. **Evidence levels:** compile/signature/catalog validated; patch-stage verified against exact APK; installed/launched on phone. Do not elevate a build to runtime-tested just because compilation passed. Keep past working versions while validating an app update.

Official references: https://reseam.app/docs/authoring/how_patching_works/ and https://reseam.app/docs/authoring/bundles/ .
