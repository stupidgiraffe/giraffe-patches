# Trigger Updates — manual patch maintenance command

The exact ChatGPT instruction **“Trigger Updates for our patches”**, used in any new conversation in the Reseam Patches project, means perform this workflow immediately. The permanent project of record is `stupidgiraffe/giraffe-patches` and Plane project `GRFP`.

1. **Discover:** Read this file and `docs/RESEAM_BUILD_CONTRACT.md`. Check the latest **official released ReSeam Manager/engine version** via `reseam.app` / `git.reseam.app` / the release API; inspect currently signed bundle manifests. Check all patches in our repo, currently Smart Launcher and Icon Pack Studio, using vendor primary release channels then APKMirror secondary. Smart Launcher's developer Telegram channel `https://t.me/s/smartlauncher` may have beta APKs before APKMirror. Distinguish beta from stable.
2. **Decide:** For each app separately, compare observed app version/code against *currently supported* app version/code and compare the ReSeam **bundle engine** against the current engine. If neither changed, do not rebuild. If engine only changed, preserve exact proven source and rebuild. If app changed, obtain the authentic original APK/APKM, verify package/version/DEX changes and re-fingerprint matchers; if binary is not available, report the blocker instead of advertising unverified support or silently broadening a target.
3. **Build:** Use its dedicated on-demand workflow only. Smart Launcher: `.github/workflows/smartlauncher-manual.yml` under `projects/smartlauncher`. Icon Pack Studio: `.github/workflows/iconpackstudio-manual.yml` under `projects/iconpackstudio`. Pin the Reseam SDK and CLI to the exact confirmed engine version and preserve signing secret `RESEAM_SIGNING_KEY_BASE64` and public key `9b5228381bdce62d03e9df9654f02c9ceb9c06fd67722aa201a6c01cc989d89b`.
4. **Guard:** Compile/test once per updated app via manual `workflow_dispatch`; never enable cron, push, pull-request, tag, auto-retry or recurring actions. Verify artifact ZIP, manifest engine and version code labels, SHA-256 file digests, Ed25519 manifest signature, and ReSeam bundle registration; do not call compilation a device test.
5. **Publish/update repository:** Update the source in a reviewable branch, only promote successful builds, refresh documentation and Plane task status, and preserve the last known working bundle/commit for rollback. Do not publish copyrighted APK binaries or private signing credentials.
6. **Deliver:** Extract the signed `.reseam` from the live successful artifact into `/mnt/data`, independently validate and provide a verified fresh downloadable link; include a short table of old/new app and engine versions, build status, and what needs a device test.

**APKMirror credentials:** APKMirror does **not** publish an official public developer API. If the user supplies a key for a specific third-party APKMirror metadata/download provider (for example Parse.bot or RapidAPI), confirm **provider, endpoint and request limits** first. Store credentials in APIVault or an approved secret manager, never Git. Validate cost, ToS and reliability, and prefer the direct Smart Launcher channel when it is newer. No API key is currently necessary to inspect a user-uploaded APK.

The trigger phrase authorizes **one-time execution** in the chat, not the creation of any future automation. It does not waive the requirement for a valid new app binary, publisher provenance, or safe verification.
