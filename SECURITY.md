# Security policy

Please avoid posting signing seeds, tokens, credentials, or private account data in public issues.

If you believe the signing key has been exposed, **do not publish a new release with it**. Report the suspected compromise privately to the maintainer through GitHub's security-advisory feature when available, or another verified contact channel. Record any key rotation prominently and independently in release notes and the compatibility record.

Patch bundles are executable code. Trust only signer fingerprints independently published here; treat any unexpected signer change as a security-relevant event. Do not import bundles from unverifiable mirrors.
